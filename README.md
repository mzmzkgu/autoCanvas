# autoCanvas (Miri Creator)

미리캔버스용 썸네일·클립아트 제작에 쓸 AI 이미지 생성 키워드와 Gemini 프롬프트를 매일 자동으로 추천해주는 대시보드.

## 구성
- `index.html` — 대시보드 페이지. `data/keywords.json`을 fetch해서 5개 카테고리(🔍조사·탐구 / 🌱성장·힐링 / 🐾우정·협업 / 🤔고민·생각 / 💡발견·아이디어)별 추천 키워드·Gemini 이미지 생성 프롬프트·해시태그를 카드로 표시. 프롬프트/해시태그 복사 버튼 제공
- `data/keywords.json` — 백엔드가 매일 갱신해서 올리는 데이터 파일 (판매 데이터 기반 분석 결과)
- `miri_keywords.py` — 키워드·프롬프트 생성 백엔드 스크립트
- `logs/run.log` — 실행 로그

## 동작 방식
서버(라즈베리파이 등)가 하루 한 번 `keywords.json`을 갱신해서 같은 저장소에 커밋 → GitHub Pages가 이를 fetch해서 렌더링. 페이지에는 다음 갱신까지 남은 시간을 보여주는 카운트다운 바가 있음.
